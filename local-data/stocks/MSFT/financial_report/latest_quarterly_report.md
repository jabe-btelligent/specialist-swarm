## Azure Growth Deep-Dive

Azure reported 31% constant-currency growth, up from 28% in Q1 FY2026 — the first reacceleration in 6 quarters. Key drivers:

- **AI workloads** contributed ~12 points of Azure growth (vs. ~9 points prior quarter)
- GPU cluster capacity additions: 400,000+ H100/H200 equivalents brought online in Q2
- AI consumption (metered billing) represents 38% of incremental Azure revenue
- Copilot Studio and Azure AI Foundry: 85,000+ enterprise customers deploying custom agents

## Key Risks

1. **Capex overhang** — $80B annual spend compresses near-term FCF; execution risk on data center timelines.
2. **Antitrust** — EU investigation into Teams bundling; ongoing FTC review of Activision integration.
3. **Azure competition** — AWS re-accelerating (27% YoY); Google Cloud growing 30%+.
4. **OpenAI dependency** — Exclusive partnership economics unclear post-OpenAI restructuring; model commoditization risk.
5. **China exposure** — LinkedIn fully exited; minimal direct revenue risk, but supply chain and sovereign cloud pressures persist.
